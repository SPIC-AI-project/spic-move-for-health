GAMES

競技紹介

オレンジ・グリーン・ピンク・ブルーの4チームに分かれて対戦します。競技ごとの順位に応じて得点が入り、合計点で総合優勝が決まります。

第1競技

大玉送り

  • 時間10:45〜11:00（15分）
  • 人数全員

各チームで列をつくり、大玉を落とさないように頭上で送ります。カラーコーンを2往復し、フラフープの中に大玉を止めたらゴール。ゴールするまでの速さを競います。

注意事項

  • スタートの合図があるまで、大玉は持ちあげないでください（触るのはOKです）。
  • 大玉を落としたら、落ちた場所からやり直しです。
  • カラーコーンの折り返しは、必ず時計回りです。
  • 11歳以下のお子様は、スタート時（大玉を持ちあげるとき）のみ参加できます。※参加は任意です

第2競技

4色玉入れ・キッズ玉入れ

  • 時間11:00〜11:25（25分）
  • 人数全員

制限時間は120秒。カゴに入れた玉の数を競います。玉の色は、オレンジ・グリーン・ピンク・ブルーの4色。4色が1個ずつそろって、はじめて1ポイントです（栄養素をバランスよくとるイメージ）。カゴの中で足りない色を見極めて、バランスよく投げ入れましょう。

キッズの部は、背の高さに応じてカゴの高さを変えて行います。

注意事項

  • 競技開始の合図まで円の外で待ち、中にある玉には触れないでください。
  • 道具を使って玉を投げるのは禁止です。
  • カゴに登るのは禁止です。
  • 肩車などをして、高さを出して投げるのは禁止です。
  • 他のチームの邪魔をするのは禁止です。

第3競技

大縄跳び

  • 時間11:25〜11:45（20分）
  • 人数1チーム20名（跳び役18名・回し役2名）

全員が縄に入った状態からスタートします。制限時間3分の間の、連続で跳んだ最高回数を競います。制限時間内は、何度でもチャレンジできます。練習時間は2分間。

注意事項

  • 練習時間以外の練習は禁止です。
  • 制限時間が終了したときに跳んでいれば、ひっかかるまで跳び続けてOKです。
  • 並び方（1列、2列など）は自由です。

第4競技

綱引き

  • 時間11:45〜12:05（20分）
  • 人数1チーム30名（4チームのトーナメント）

制限時間30秒の1本勝負。自陣に2m以上引き込むか、30秒経過した時点で、より綱を引いていたチームの勝ちです。

注意事項

  • 人数が揃ったチームは、座って待機してください。
  • スタートの笛が鳴るまで、綱を引かないでください（触るのはOKです）。
  • 体に綱を巻き付けるのは禁止です。
  • 綱を引く際に手が擦れる場合がありますので、気になる方は軍手などをご持参ください。

第5競技

スピックウルトラクイズ

  • 時間12:50〜13:15（25分）
  • 人数全員

4択クイズに挑戦します。シンキングタイム（30秒）の間に、答えだと思う回答スペースへ移動。間違えたら、すみやかに応援ブースへ戻ります。4問のクイズを出題し、最後の問題が終わったときに残っていた人数で、順位が決まります。2回戦を行い、それぞれで順位を決めて得点が入ります。

注意事項

  • 応援ブースから、回答中の選手に答えを教えるのは禁止です。
  • 携帯電話などで答えを調べるのは禁止です。
  • シンキングタイムが終わったあとの移動はできません。

第6競技

増殖障害物競走

  • 時間13:15〜13:35（20分）
  • 人数1チーム15名

タスキをつなぐたびに、走る人数が増えていく障害物リレー。1人、2人組、3人組、4人組、5人組の順に、毎回ちがうメンバーが走り、チーム合計15名でタスキをつなぎます。

障害物（走る順）

  • パターゴルフ（1人）
  • ラグビーボールドリブル（2人）
  • 3人4脚（3人）
  • おたまピンポンリレー（4人）
  • ムカデ競争（5人）

注意事項

  • パターゴルフは、入ったら走らずにタスキを渡してください。
  • ラグビーボールは、交互に蹴りゴールラインに止めてください。
  • ムカデは先頭がゴールラインを超えたらゴールです。

第7競技

キッズかけっこ／ガチンコリレー

  • 時間13:35〜14:10（35分）

キッズかけっこ

11歳以下のお子様向けの、直線のかけっこです。未就学児の部と小学生の部に分け、スタートの位置を変えて行います。未就学児は、大人のサポートもOKです。年齢に合わせた実施のため、チーム対抗ではなく、得点はありません。

ガチンコリレー（1チーム10名）

トラックをバトンでつなぎ、アンカーがゴールするまでの速さを競います。走るのは、全員ひとり1周です。
※1人あたり約100mを想定しています。

  • バトンは、バトンゾーンの中で受け渡してください。
  • 走り終わった人は、次の走者の妨げにならないよう、トラックの内側で待ってください。
  • 同じチームのフライングが2回になると、失格です。
